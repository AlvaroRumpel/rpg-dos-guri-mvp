# Handoff - RPG dos Guri MVP

Data: 2026-05-31

## Resumo

O projeto e um Flutter Web/PWA para apoiar uma mesa pequena de RPG. O app controla fichas, combate manual, vida, status, poderes, consumiveis, monstros e progressao sem automatizar rolagens ou decisoes do mestre.

URL publicada:

```text
https://rpgdosguri.web.app
```

Projeto Firebase:

```text
rpg-dos-guri-6b16e
```

## Ultimas Alteracoes

- Adicionado PIN domestico do mestre com hash por mesa e autorizacao salva localmente.
- Adicionado deep link de mesa no formato `?mesa=GURI-1234`.
- Adicionado cache local da ultima mesa e ultima ficha selecionada com `shared_preferences`.
- Adicionada fila persistida de pedidos de uso de poder/magia.
- Jogador solicita uso; mestre aprova ou descarta no painel.
- Adicionado arquivamento/restauracao de fichas pelo mestre.
- Fichas arquivadas somem da landing, companhia ativa e novos combates.
- Adicionados resets manuais por sessao e descanso longo.
- Mantido reset automatico apenas para poderes por combate ao finalizar combate.
- Corrigido mojibake em strings e no normalizador de nomes oficiais.
- Atualizados Firestore Rules, README e status de implementacao.
- Adicionado checklist manual em `docs/manual-qa-checklist.md`.
- Atualizado widget test e adicionados testes de controller.

## Seguranca

O PIN do mestre e uma barreira domestica contra acesso casual. Ele nao e autenticacao forte contra usuario malicioso. As regras Firestore continuam permitindo leitura publica e atualizacoes validadas por formato.

Uma evolucao futura pode usar Firebase Auth anonimo com papeis ou Cloud Functions para validar autorizacao no backend.
